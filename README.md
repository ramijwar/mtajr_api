# SouqLink PHP API (SQLite)

هذا المجلد يحتوي على REST API مرجعية مكتوبة بـ PHP 8.2+ وPDO ومجهزة للعمل مع **قاعدة بيانات SQLite 3** مع دعم الإنشاء التلقائي لقاعدة البيانات ومخططها والجداول عند أول تشغيل.

## الإعداد

1. انسخ ملف الإعدادات:
   ```bash
   cp config.local.php.example config.local.php
   ```
2. اضبط المتغيرات داخل `config.local.php` أو عبر متغيرات البيئة:
   - `DB_PATH`: مسار ملف قاعدة بيانات SQLite (الافتراضي: `storage/database.sqlite`).
   - `JWT_SECRET`: سلسلة عشوائية بطول 64 محرفاً أو أكثر لتشفير الرموز.
   - `CORS_ORIGINS`: النطاقات المسموح لها بالاتصال (أو اتركه فارغاً للكل).
   - `UPLOAD_PATH`: مسار رفع الصور (الافتراضي: `storage/uploads`).
   - `MAX_PRODUCT_IMAGE_BYTES` و `MAX_PROOF_IMAGE_BYTES`.

3. **إنشاء قاعدة البيانات**:
   - يتم إنشاء قاعدة البيانات وجداولها والبيانات الأولية تلقائياً بمجرد تشغيل الخادم إذا لم تكن موجودة.
   - أو يمكنك تشغيل أمر الإنشاء اليدوي عبر سطر الأوامر:
     ```bash
     php database/init_sqlite.php
     ```

| المتطلب | الحد الأدنى |
|---|---|
| PHP | 8.2+ مع امتدادات `pdo_sqlite`، `sqlite3`، `fileinfo`، و`mbstring` |
| قاعدة البيانات | SQLite 3 (مدمجة ولا تحتاج خادم منفصل) |
| الخادم | أذونات كتابة لمجلد `storage/` ومجلد `storage/uploads/` |
| الأسرار | `JWT_SECRET` بطول 64 محرفاً عشوائياً أو أكثر |

## مسار التشغيل وقاعدة البيانات

- يتم تخزين قاعدة البيانات بأمان داخل مجلد `storage/database.sqlite` وهو محمي من الوصول المباشر عبر الويب بواسطة ملف `storage/.htaccess`.
- مفعّل في SQLite وضع `WAL` (Write-Ahead Logging) لسرعة وكفاءة العمليات المتزامنة مع تفعيل مفاتيح الربط الأجنبية `PRAGMA foreign_keys = ON`.
- تم تحويل كافة استعلامات الخادم والمخططات لدعم SQLite بالكامل.
- مخطط SQLite الكامل متاح في `database/schema.sqlite.sql` وبيانات المدن العربية في `database/seed_marketplace_arab_cities.sqlite.sql`.

## التغطية الحالية

يتضمن `index.php` نقاط بداية قابلة للتشغيل للمصادقة، المتاجر والمنتجات، الحراج، السلة، إنشاء الطلبات المعاملاتي، سند شام كاش، مهام التوصيل، إثبات الاستلام، المحافظ والسحوبات، وتذاكر الدعم.
