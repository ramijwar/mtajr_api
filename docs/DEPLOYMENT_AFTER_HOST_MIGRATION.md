# نشر تحديث الإدارة والملفات الشخصية بعد نقل الاستضافة

لا تطبق هذه الحزمة على استضافة InfinityFree المجانية الحالية لأنها تعيد تحدي JavaScript إلى تطبيق Android بدلاً من JSON. انقل API وقاعدة MySQL أولاً إلى بيئة تدعم REST API.

## ترتيب ترحيلات MySQL

نفّذ الترحيلات مرة واحدة بالترتيب التالي على قاعدة البيانات المنقولة، مع تجاوز الملفات التي طُبقت بالفعل في القاعدة الجديدة:

1. `20260822_add_verifications.sql`
2. `20260822_add_financials.sql`
3. `20260822_add_profile_and_admin_management.sql`

الترحيل الثالث يضيف `profile_update_permission` ويضبط الحسابات الموثقة مسبقاً إلى `locked`. عند اعتماد طلب توثيق جديد يقفل API تعديل الملف تلقائياً، ويمكن للمدير تغيير الصلاحية إلى `allowed` أو `locked` من إدارة المستخدمين.

## ملفات API المطلوبة

ارفع محتويات `public/` و`src/` إلى جذر API الجديد مع إنشاء `storage/uploads/` بصلاحية كتابة. لا تنسخ أي `config.local.php` أو أسرار إلى الحزمة؛ أنشئ إعداد اتصال قاعدة البيانات في الخادم الجديد فقط.

## فحص ما بعد النشر

تحقق من أن `GET /health` يعيد JSON من عميل غير متصفح. ثم اختبر إنشاء الحساب، `GET /profile`، قوائم `GET /admin/users` و`GET /admin/stores` و`GET /admin/couriers`، وطلبَي التوثيق المفصولين باستخدام `subject_role=merchant` و`subject_role=courier`.
