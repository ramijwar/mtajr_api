# نشر توسعة الإدارة

تمت إضافة مسارات إدارة لإنشاء وتعديل المستخدمين والمتاجر وملفات عمال التوصيل مع التحقق من الإدخال، منع إنشاء أو ترقية المديرين من هذا المسار، والتحقق من تكرار الهاتف والبريد، وسجل تدقيق لكل تغيير.

تجتاز واجهة Flutter تحليل الأنواع من دون أخطاء بناء أو تحذيرات، واجتازت اختبارات Flutter قبل النشر. جرى فتح مدير ملفات cPanel وتحديد مجلد `public_html/mtajr_api` تمهيداً لرفع `index.php` بعد الاحتفاظ بنسخة الخادم الموجودة عبر واجهة الاستضافة.

ظهر ملف `index.php` الإنتاجي الحالي داخل المجلد المحدد، وقد اختير لحفظ نسخة احتياطية قبل الاستبدال.

اكتمل تنزيل النسخة الاحتياطية بنجاح في بيئة العمل قبل متابعة النشر.

أعاد مدير الملفات عرضه إلى المجلد الرئيسي بعد الانتقال من سجل التنزيلات؛ سيُفتح مجلد API من زر الانتقال نفسه قبل اختيار الرفع.

فُتحت واجهة الرفع في المجلد الصحيح وتعرض خيار استبدال الملف القائم؛ لم يُرفع أي ملف بعد في هذه المرحلة.

فُعّل خيار الاستبدال وظهر حقل رفع الملف في الواجهة؛ الملف التالي سيستبدل `index.php` في مجلد API فقط.
