# حالة الاستضافة

تم فتح صفحة تسجيل دخول لوحة InfinityFree على الرابط `https://cpanel.epizy.com/`. تعرض الصفحة حقلي اسم المستخدم وكلمة المرور وزر تسجيل الدخول، ولا تتضمن قبل الدخول أي اسم قاعدة بيانات أو مضيف MySQL أو إعدادات FTP.

بعد تسجيل الدخول ظهرت بيانات التشغيل غير السرية التالية: النطاق الرئيسي هو `6hprzvnd.infinityfree.com`، مضيف FTP هو `ftpupload.net`، ومضيف MySQL هو `sql204.infinityfree.com`. تظهر اللوحة أن الحساب يتيح قاعدة MySQL واحدة؛ يلزم تأكيد اسم القاعدة الموجود أو إنشاء قاعدة جديدة قبل إعداد متغيرات خادم PHP.

تبيّن من صفحة MySQL أن الحساب يستخدم قاعدة موجودة باسم `if0_42695545_t3lam_app`، وهي ليست قاعدة SouqLink. يمكن إنشاء قاعدة مستقلة جديدة باسم لاحقته `souqlink`، وستستخدم كلمة مرور لوحة الاستضافة نفسها للمستخدم وقاعدة البيانات وفقاً لتعليمات اللوحة.

تم إنشاء قاعدة SouqLink بنجاح باسم `if0_42695545_souqlink`. يستخدم الاتصال الإنتاجي خادم `sql204.infinityfree.com` ومستخدم MySQL الخاص بالحساب، وتبقى كلمة المرور خارج المستودع وضمن إعدادات الاستضافة فقط.

تم استيراد المخطط في قاعدة SouqLink بنجاح عبر phpMyAdmin، ونفذت الأداة 22 استعلاماً لإنشاء جداول المنصة وعلاقاتها دون إدخال بيانات اختبار.

اعتمد المستخدم النطاق العام `t3lam.free.nf` ومسار النشر `mtajr_api`. يكون رابط فحص الصحة المستهدف بعد الرفع هو `https://t3lam.free.nf/mtajr_api/health`، ويجب عدم استخدام المجلد المحجوز `api` في هذا الحساب.

تم إنشاء المجلد العام `htdocs/mtajr_api` في مدير الملفات، وهو فارغ وجاهز لرفع حزمة خادم SouqLink.

تم رفع واستخراج حزمة SouqLink بنجاح في `htdocs/mtajr_api`. يحتوي المسار الآن على `index.php` و`src/` و`storage/` وملف الإعداد المحلي وملفات `.htaccess` المطلوبة، وهو جاهز لاختبار مسار الصحة عبر HTTPS.

أظهر اختبار `https://t3lam.free.nf/mtajr_api/health` استجابة `not_found` من التطبيق نفسه، ما يؤكد وصول الطلب إلى PHP ويشير إلى ضرورة إزالة بادئة المسار الفرعي `mtajr_api` داخل توجيه التطبيق قبل إعادة اختبار الصحة.

تم تجهيز إصدار مصحح من `index.php` يزيل بادئة المسار الفرعي تلقائياً قبل مطابقة المسارات، وتحقق فحص PHP المحلي من سلامة صياغته قبل الرفع.

تم استبدال `htdocs/mtajr_api/index.php` بالإصدار المصحح بنجاح، وتظهر لوحة الملفات الحجم والتوقيت المحدثين للملف.

نجح اختبار رابط الصحة النهائي عبر HTTPS. يعيد `https://t3lam.free.nf/mtajr_api/health` الاستجابة `{"data":{"status":"ok","service":"souqlink-api"}}`، ما يؤكد أن خادم SouqLink العام يعمل وأن توجيه المسار الفرعي صحيح.

نجح اختبار القراءة `https://t3lam.free.nf/mtajr_api/products` وأعاد `{"data":[]}`. تؤكد هذه الاستجابة اتصال PHP بقاعدة MySQL المنشورة مع عدم وجود منتجات منشأة بعد.

لا تُخزّن كلمات المرور أو مفاتيح النشر داخل هذا المشروع. قبل تجهيز النشر الفعلي يلزم الحصول من لوحة الاستضافة بعد تسجيل الدخول على: اسم قاعدة MySQL، اسم مستخدم MySQL، مضيف MySQL، اسم النطاق أو المسار العام الذي سيستضيف `public/`، وطريقة رفع الملفات المفضلة (مدير الملفات أو FTP).
