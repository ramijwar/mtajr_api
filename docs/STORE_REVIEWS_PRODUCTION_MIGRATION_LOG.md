# سجل ترحيل تقييمات المتاجر في الإنتاج

**التاريخ:** 2026-08-23

## نطاق العملية

نُفّذ الترحيل داخل قاعدة بيانات SouqLink الإنتاجية فقط. أضيفت حقول متوسط التقييم وعدد المراجعات إلى جدول `stores`، وأُنشئ جدول `store_reviews` للمراجعات المرتبطة بالعميل والطلب والمتجر.

## التحقق

أظهرت واجهة إدارة قاعدة البيانات نجاح عمليتي `ALTER TABLE` و`CREATE TABLE` دون صفوف نتيجة، وهي نتيجة متوقعة لعمليات تغيير المخطط. استُخدمت صيغ `IF NOT EXISTS` لتكون العملية قابلة للإعادة بأمان.

## الضوابط التطبيقية المرتبطة

لا يسمح API بإضافة تقييم متجر إلا للعميل صاحب طلب حالته `delivered` في المتجر نفسه، ويمنع المفتاح الفريد تكرار تقييم المتجر ضمن الطلب الواحد.
