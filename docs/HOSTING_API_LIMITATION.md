# قيد الاستضافة الحالية لتطبيق SouqLink

أثبت اختبار طلب التسجيل من عميل Dart أن نطاق InfinityFree المجاني يعيد صفحة HTML تحتوي تحدي JavaScript بدلاً من JSON. لذلك لا يستطيع تطبيق Android الاتصال بـ REST API رغم سلامة كود PHP.

توضح وثائق InfinityFree أن حماية المتصفح إلزامية في الحسابات المجانية، وتتطلب JavaScript وملفات تعريف الارتباط، وتمنع تطبيقات Android وiOS وREST API وطلبات cURL، ولا يمكن تعطيلها في الخطة المجانية.[1]

لا يُنشر هذا التحديث إلى الاستضافة الحالية. يجب تطبيق حزمة API والترحيلات بعد الانتقال إلى استضافة تسمح بطلبات API الأصلية أو إلى خدمة مدفوعة متوافقة. تشير صفحة InfinityFree إلى iFastNet كخيار مدفوع وتذكر إمكانية النقل المجاني من InfinityFree.[2]
