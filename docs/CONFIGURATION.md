# متغيرات إعداد الخادم

لا تُحفظ القيم السرية داخل المستودع. أضفها إلى لوحة الاستضافة أو مدير أسرار الخادم عند النشر.

| المتغير | الغرض | متطلب النشر |
|---|---|---|
| `DB_HOST` و`DB_PORT` | عنوان ومنفذ MySQL | إلزامي |
| `DB_DATABASE` | اسم قاعدة SouqLink | إلزامي |
| `DB_USERNAME` و`DB_PASSWORD` | حساب قاعدة بيانات محدود الصلاحيات | إلزامي |
| `JWT_SECRET` | توقيع رموز الوصول | إلزامي، عشوائي بطول 64 محرفاً أو أكثر |
| `CORS_ORIGINS` | النطاقات المسموح لها بالاتصال | إلزامي في الإنتاج، قائمة مفصولة بفواصل |
| `UPLOAD_PATH` | مسار خارج جذر الويب للصور المرفوعة | إلزامي في الإنتاج |
| `MAX_PRODUCT_IMAGE_BYTES` | الحد الأعلى لصورة المنتج بعد ضغط التطبيق | يوصى بـ 4 ميغابايت |
| `MAX_PROOF_IMAGE_BYTES` | الحد الأعلى لإثبات التسليم | يوصى بـ 5 ميغابايت |

يجب عدم استعمال حساب MySQL بصلاحيات مدير النظام في الإنتاج. امنح حساب التطبيق صلاحيات `SELECT` و`INSERT` و`UPDATE` و`DELETE` اللازمة لقاعدة `souqlink` فقط، مع نسخ احتياطي ومراجعة دورية لسجل التدقيق.
