# نشر تفعيل الطلبات والدعم

يشمل ملف API المحلي تحسينات الطلبات للتاجر وعامل التوصيل، ومراجعة إثبات التسليم من الإدارة، وتصحيح حالة رد الإدارة في الدعم إلى حالة صالحة، ومنع حساب الإدارة من إنشاء تذاكر جديدة مع تمكينه من الحل والإغلاق والحذف.

تم فتح مدير ملفات الاستضافة وتحديد مسار `public_html/mtajr_api` لنشر ملف `index.php` المحدث. تُجرى بعد النشر اختبارات عامة آمنة لمسارات API وحماية المسارات المقيدة، من دون إنشاء طلبات أو تذاكر اختبارية.
